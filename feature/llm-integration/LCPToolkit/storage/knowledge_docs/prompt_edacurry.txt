# EDACurry Library Documentation

The following lines provides a comprehensive overview of the `edacurry` Python library, which is designed for parsing, manipulating, and generating circuit netlists. It details the library's core concepts, class hierarchy, attributes, methods, module-level functions, and enums.

---

## Core Concepts

The `edacurry` library represents circuit definitions as an Abstract Syntax Tree (AST). Each element of a netlist—such as components, subcircuits, nodes, parameters, and various types of values—is an Object within this tree. This hierarchical structure allows for powerful and flexible manipulation of circuit data. The Visitor design pattern is utilized, enabling distinct operations (like printing or analysis) to be performed on the AST without modifying the core structure classes.

---

These functions provide the primary interface for interacting with the `edacurry` library, handling parsing from various netlist formats, writing to them, and searching within the Abstract Syntax Tree.

# Example 2: Wrapping an existing subcircuit (OPAMP1) into a new subcircuit for hierarchical reuse or probing.
// Step 1: Find and rename OPAMP1 to OPAMP1_WP
original = edacurry.find_subckt(root, "OPAMP1")
original.name = "OPAMP1_WP"
// Step 2: Create wrapper subckt OPAMP1 with same ports
wrapper = edacurry.Subckt("OPAMP1")
for node in original.nodes:
    wrapper.nodes.append(edacurry.Node(node.name))
// Step 3: Create a component that instantiates OPAMP1_WP
xopamp = edacurry.Component("XOP1", ("OPAMP1_WP"))
for node in original.nodes :
    xopamp.nodes.append(edacurry.Node(node.name))
wrapper.content.append(xopamp)
// Step 4: Add the wrapper back to the root
root.content.append(wrapper)

# Example 4: Updating the W parameter of all nmos1 components.
import numpy as np , edacurry , os
// If the output directory does not exist , create it
if not os.path.exists("eldo_result"):
    os.mkdir("eldo_result")
// Parse the ELDO file
root = edacurry.parse_eldo("eldo/circ_base/opamp.cir")
// Sweep width parameters from 1 um to 5 um , 5 points
width_values = np.linspace(1.0, 5.0, 5)
// Find the subcircuit "OPAMP1"
subckt = edacurry.find_subckt(root, "OPAMP1")
// Find all NMOS components inside the subcircuit .
comps = edacurry.find_components_by_master(subckt, "nmos1")
// For each width value ...
for width in width_values:
    // Update each NMOS width
    for nmos in comps:
        // Find the parameter "W"
        w_param = edacurry.find_parameter(nmos, "W")
        // Update the parameter value.
        w_param.right = edacurry.Double(width)
    // Output each variant netlist.
    filename = f"eldo_result/variant_w_{width:.1f}.cir"
    with open(filename, "w") as f:
            f.write(edacurry.write_eldo(root))
